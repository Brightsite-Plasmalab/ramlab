# Ramlab
Python module for spectral synthesis and fitting of spontaneous Raman scattering.

## Requirements
- Python 3.x. It is tested on Python 3.13. Open an issue if you find it does not work on a different version.

## Installation
1. Clone this repo using your Git GUI (Github Desktop, Sourcetree) or CLI using <br/>
`git clone git@github.com:Brightsite-Plasmalab/ramlab.git`
<!-- 1. (Optional) to install this module in a virtual environment, [activate it](https://docs.python.org/3/library/venv.html#how-venvs-work). -->
2. Install the module using `pip install -e [path_to_ramlab]`, replacing `[path_to_ramlab]` with the directory of this README.


## Usage

This module consists of several sub-modules:
1. Transition line list calculation
2. Stick spectra simulation
3. Spectral synthesis
4. Fitting of experimental data
