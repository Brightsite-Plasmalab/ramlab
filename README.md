## Installation
1. Clone this repo using your Git Client of choice, or <br/>
`git clone git@github.com:Brightsite-Plasmalab/ramlab.git`
2. (Optional) to install this module in a virtual environment, [activate it](https://docs.python.org/3/library/venv.html#how-venvs-work).
3. Install the module using `pip install -e [path_to_ramlab]`, replacing `[path_to_ramlab]` with the git repo directory.

This module consists of several sub-modules:
1. Transition line list calculation
2. Stick spectra simulation
3. Spectra simulation
4. Spectral fitting
